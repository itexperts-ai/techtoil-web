# Techtoil Web

Marketing site for **Techtoil** — product design, development, marketing (SEO/SMO/LeadGen), startup consultancy, funding support, AI operations automation, and HR hiring (OnRole / OffRole).

## Stack

- React + TypeScript (Vite)
- Framer Motion
- Custom Techtoil brand mark (SVG)

## Local

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
