# Techtoil Web

Premium marketing site for **Techtoil**.

## Seven services (each is a full chapter)

1. Product Design  
2. Product Development  
3. Marketing Solution — SEO / SMO / LeadGen  
4. Startup Consultancy  
5. Funding Support for Startups  
6. Operations Automation through Artificial Intelligence  
7. HR Hiring Support — OnRole / Off Role  

## Local

```bash
npm install
npm run dev
```

Default: [http://localhost:5174](http://localhost:5174) (or the port Vite prints).

## Stack

React + TypeScript (Vite), Framer Motion, Unbounded + Figtree, custom brand lockup.
