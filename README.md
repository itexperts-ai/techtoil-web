# Techtoil Web

Premium AI-powered business growth website for **Techtoil**.

## Positioning

**From Vision to Execution. From Startup to Scale.**

One integrated ecosystem — not seven disconnected agency cards.

## Seven pillars (left menu)

1. Product Design  
2. Product Development  
3. Marketing Solutions — SEO / SMO / LeadGen  
4. Startup Consultancy  
5. Funding Support for Startups  
6. AI-Powered Operations Automation  
7. HR Hiring Support — OnRole / Off Role  

## Stack

React · Vite · TypeScript · Tailwind CSS v4 · React Router · Framer Motion · Lucide

## Local

```bash
npm install
npm run dev
```

## Notes

- Logo is a crafted SVG lockup (not a pasted raster image).
- Business Navigator is a **demo** rule-based assistant until an LLM backend is wired.
- Consultation forms validate on the client and expose a clear `POST /api/leads` integration point (no fake success).
